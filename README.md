# 书签管理器

Chrome / Firefox 书签管理扩展，提供侧边栏、管理器、搜索、标签分组、捷径、常用访问统计，以及本地和 WebDAV 备份。

当前开发版本：**1.4.6**。修复已在统一源码中实施；真实浏览器发布验收尚未完成，详见 [执行与验证记录](docs/IMPLEMENTATION_STATUS.md)。

## 开发与构建

需要 Node.js 24 和 npm。扩展运行时不依赖 Node.js。

```sh
npm ci
npm run verify
```

- `npm run build`：从 `src/` 生成 `dist/chrome/`、`dist/firefox/`。
- `npm run lint`：检查源码正确性。
- `npm test`：构建并执行 Node API 模拟和 jsdom DOM 集成测试。
- `npm run check`：检查语法、顶层重复函数及打包资源引用。
- `npm run verify`：运行上述自动化检查。
- `npm run test:browser`：使用 Playwright 和隔离临时配置运行 Chrome 扩展冒烟测试；不会读取日常浏览器书签。

首次运行浏览器测试需 `npx playwright install chromium`。可通过环境变量 `BOOKMARK_CHROMIUM_PATH` 指定兼容的 Chromium 可执行文件。测试输出临时配置目录和截图路径。当前 Windows 环境启动浏览器失败，不能将单元测试通过视为浏览器验收通过。

## 加载扩展

先运行 `npm run build`。

- Chrome：打开 `chrome://extensions`，启用开发者模式，选择“加载已解压的扩展程序”，加载 `dist/chrome/`。最低声明版本为 Chrome 116；最低版本实际兼容性仍需验收。
- Firefox：打开 `about:debugging#/runtime/this-firefox`，选择“临时载入附加组件”，打开 `dist/firefox/manifest.json`。当前输出 MV2 后台脚本，构建目标 Firefox 115；最低支持版本尚未实测。临时加载在重启后失效。

不要加载仓库根目录。发行包应只包含对应 `dist` 浏览器目录的内容。

## 源码结构

```text
src/
  background.cjs        后台消息、调度和串行队列
  platform/             原生 API 和书签根适配
  services/             备份恢复、领域写入、WebDAV、图标缓存
  shared/               页面共享工具、统计、国际化、虚拟列表和样式
  ui/manager/           管理器与设置页
  ui/sidebar/           侧边栏
manifests/              两浏览器差异配置
scripts/                构建与校验
tests/                  API 模拟、DOM 集成和浏览器冒烟
docs/                   实施计划与验收记录
dist/                   生成文件，不提交、不手工编辑
```

修改 `src/` 后重新构建即可生成两种扩展。构建发现的旧产物会移至 `dist/.stale/`，不会混入可加载目录或 CI 发行产物。

恢复预览凭证优先保存到浏览器会话存储，不支持时使用本地存储，因此后台休眠不会丢失预览。最多保留 4 条，超过 24 小时的记录在下次访问预览缓存时清理。凭证丢失时会重新比对：备份内容、本地书签、标签、捷径、布局和模式完全一致才沿用确认，否则展示新预览。已经提交的恢复不会因连接中断自动重试；请先检查恢复结果和快照状态。存储配额不足时会明确报错并停止，不绕过预览或快照保护。

## 备份与恢复

新备份使用独立的 `schemaVersion: 2`，每个书签保存自己的标签，重复网址可以有不同标签。本地和 WebDAV 使用相同的校验与恢复服务。

恢复先预览再确认；预览绑定合并/覆盖模式及当前书签树，10 分钟后或后台重启后失效。书签发生变化时需重新预览。布局导入只更新经过校验的布局字段。

本地与云端书签恢复共用差异预览：按新增、删除、变更、匹配、本地保留和受管跳过分类，支持搜索和分页；展开条目可查看目录、标题、URL、标签及恢复前后数据。覆盖模式显示内容差异，但实际仍会删除并重建所选目录的可写节点。预览后标签、捷径或布局变化也会要求重新预览。

合并按同一父目录中的标题、网址和重复出现次序匹配；本地捷径标题与顺序优先，新增网址追加。覆盖只重建备份所含的可写根，无法匹配的根保存为可见的 Imported 文件夹。

执行前保存并读回校验本地恢复快照。失败或中断后停止自动备份与后续领域修改，在设置页导出快照或执行快照恢复。快照包含私人书签和标签，按备份文件妥善保管。书签 API 没有事务，补偿恢复会产生新 ID；不能保证原子回滚，也不能撤销同时发生的外部编辑。

旧备份有完整书签树时可迁移 ID 标签；只有标签且没有配套树的文件会被拒绝。旧 URL 标签备份已丢失的重复网址标签差异无法还原。未知新版本备份不会尝试写入。

WebDAV 默认需用户配置和启用；关闭自动备份会清除定时任务。已被服务器接受的上传无法因关闭开关而撤回。上传成功后才清理可识别的旧备份，清理失败作为警告反馈，恢复不删除远端备份。
