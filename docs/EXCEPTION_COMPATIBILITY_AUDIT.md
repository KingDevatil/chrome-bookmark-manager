# 异常提示与兼容性检查（2026-09-07）

本次检查以设置、导入、备份恢复、WebDAV 和平台适配为主。自动测试使用模拟浏览器 API 和 jsdom，不能替代真实浏览器及服务器联调。

## 已修复的缺口

| 场景 | 当前处理 |
| --- | --- |
| WebDAV 401、403、404、405、409、413、429、507 | 显示 HTTP 状态、原因及处理建议，保留状态码供目录创建逻辑判断 |
| 网络失败、请求超时、配置变更导致取消 | 分别提示网络/证书检查、30 秒超时、重新操作；释放计时器和请求控制器 |
| 云端返回空文件、损坏 JSON 或登录 HTML | 明确提示不是有效 JSON 备份，不执行恢复 |
| 无效服务地址、账号嵌入地址、查询参数或锚点 | 拒绝并说明有效配置格式 |
| 本地 JSON 错误、存储配额不足、扩展上下文失效 | 提供中文说明和恢复步骤 |
| WebDAV/自动备份设置保存失败或后台应用失败 | 捕获错误，不再无条件显示保存成功 |
| 备份成功但清理失败、备份跳过 | 页面显示警告或未执行原因，不再显示无文件名的成功消息 |
| 错误提示或长任务提示 | 保留至下一条状态；新状态取消旧成功提示的隐藏计时器 |
| 用户取消恢复 | 显示中性提示“已取消恢复，未修改数据” |
| 预览结果缺少令牌或差异列表 | 阻止确认恢复，要求重新加载扩展及页面 |
| 浏览器不支持原生模态窗口 | 明确要求升级并停止恢复；不退化成无预览覆盖 |

## 已有且经过回归测试的保护

- 导入先验证版本、字段、节点数、深度及大小；不合法输入不写入数据。
- 恢复前保存并回读快照，忽略对象字段顺序差异，但检查实际内容和数组顺序。
- 快照写入/校验失败发生在删除书签之前。
- 预览令牌绑定内容、模式和时效；书签或关联数据变化后要求重新预览。
- 恢复失败/中断保留快照和进度记录，阻止普通数据写入；可显式恢复到快照。
- 检测到外部书签修改时停止恢复；完成或失败后释放事件监听。
- Chrome/Firefox 根目录按语义映射；无法匹配的根目录使用 Imported 文件夹；受管理内容跳过。
- 合并保留重复节点出现次数和本地捷径；旧标签文件缺少书签树时拒绝猜测 ID。
- WebDAV 支持命名空间前缀变化、UTF-8 账号，拒绝 XML 实体和文件路径穿越；只有 404 才尝试创建目录。
- 恢复不删除远程备份；备份成功后的清理失败不改判上传失败。

## 尚存边界及后续建议

1. 自动备份失败主要进入后台日志，缺少持久的“最近一次成功/失败”面板。建议保存运行时间、结果和错误摘要，在设置页展示。
2. 初始化、部分旧设置操作和恢复面板加载仍存在未统一的错误捕获。建议后续逐入口改造，避免用全局吞异常掩盖失败。
3. 时间戳备份上传成功但 bookmarks.json 更新失败时，目前整个操作报告失败；历史文件可能已存在。可增加部分成功结果，提示从历史列表恢复。
4. 恢复是补偿机制而非事务回滚。浏览器强制退出仍需用户查看快照；不能承诺所有中断点自动续传。
5. 不对认证、权限或破坏性写入进行盲目重试，也不在预览缺失时绕过确认。
6. Chrome 最低声明版本、真实 Firefox、各家 WebDAV 服务以及超大备份性能仍需实际验收。原生 API 不存在时并非所有页面都有完整降级。
