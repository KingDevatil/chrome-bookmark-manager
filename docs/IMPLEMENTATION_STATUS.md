## 自动化证据

本次 `npm run verify` 已通过：48/48 测试、ESLint、Chrome/Firefox 构建和资源/语法检查。测试集合包括：

- 无效备份零写入；重复 URL 标签、旧 ID 映射、跨根恢复、重复导入幂等。
- 100 个串行化并发标签命令；快照失败、中途失败、重启后补偿和外部编辑冲突。
- 预览模式不可改变、书签变化使预览失效；非法布局零写入及未提供字段保留。
- 上传后清理失败保留成功结果；恢复不触发远端请求。
- DAV XML、路径穿越、UTF-8、图标数据转换与超限拒绝。
- 管理器、侧边栏、设置页的 jsdom 加载和特殊字符；列表双向拖拽索引与搜索禁用。
- 10,000 条书签的合成 DOM 测试：列表窗口不超过 40 行、选择覆盖完整 10,000 条、滚动更新窗口。
- 1,000 个同源缓存读取共享一次 storage.get；历史统计同时请求共享执行且并发不超过 6。

`npm audit`：本次返回 0 个已知漏洞；这不是全面安全审计。`git diff --check` 用于检查已跟踪改动的空白错误。

以上 API 数量与 DOM 数量为合成测试证据，不能推断实际首屏 ≤1 秒、搜索 P95 ≤200ms 或耗时改善 ≥50%。未采集可信的旧版/新版真实性能对照。

## 环境阻塞与尚未完成项

1. **真实 Chrome 验收阻塞**：Playwright Chromium 153.0.8010.12 和 134.0.6998.35 均在 Windows 启动时报 `spawn UNKNOWN`；新版直接启动还报告“应用程序的并行配置不正确”。尚未加载扩展、生成真实截图或完成浏览器性能测量。
2. **Firefox 尚未实测**：Promise API 模拟及 MV2 构建通过不等于 Firefox sidebar、生命周期或跨浏览器完整往返通过。
3. **WebDAV 联调待做**：目前用受控响应验证协议路径，未对真实 WebDAV 服务测试非 ASCII 凭据、代理差异、断线和权限错误。没有自动网络重试策略；错误明确返回，避免隐式重复写入。
4. **交互边界待验收**：真实 Chrome/Firefox 的移动 index 语义、跨目录及嵌套文件夹拖拽、虚拟列表 Shift 多选和拖拽滚动、主题/语言/窄侧栏需要实际浏览器验证。
5. **性能后续范围**：网格未虚拟化；历史统计尚非增量；书签事件会失效缓存并按需全树校正；侧栏展开未全面局部更新。先测量后决定进一步改造，原计划性能指标尚未关闭。
6. **模块化仍有后续空间**：shared/utils.js 和页面控制器仍较大，未机械拆成原建议目录的全部细分模块。后台、恢复、领域写入、WebDAV 和平台已分离。
