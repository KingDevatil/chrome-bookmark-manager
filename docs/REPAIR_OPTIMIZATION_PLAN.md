# 剩余修复与验收计划

更新日期：2026-09-05。已实施内容和自动化结果见 [执行记录](IMPLEMENTATION_STATUS.md)。本文替代迁移前的阶段估时、旧文件路径和待实施清单。

## 发布前必须验收

1. 在隔离配置加载 Chrome、Firefox 生成包，验证侧栏、管理器、设置、搜索、标签、捷径、主题和语言。
2. 验证原生拖拽 index 语义、双向排序、跨目录移动、自身/后代保护，以及虚拟列表滚动、多选和拖拽。
3. 验证后台冷启动、休眠唤醒、关闭自动备份、禁用 WebDAV 时取消请求。
4. 完成旧备份及 Chrome/Firefox 往返恢复，覆盖重复 URL 标签、同名文件夹和不同根目录。
5. 使用合成数据执行快照持久化失败、恢复硬中断、外部编辑和补偿恢复；确认失败不报告成功。
6. 对真实 WebDAV 服务验证 Unicode 凭据、401/403/404/5xx、超时、备份保留与清理范围。
7. 核实最低浏览器版本与商店声明，并仅打包对应 dist 浏览器目录。

当前 Windows 的两个 Chromium 测试运行时均启动失败；自动化 API/DOM 模拟通过不能替代上述验收。具体阻塞见执行记录。

## 性能测量与后续实现

同设备、同浏览器版本，使用 1,000/10,000 条书签及历史 URL，区分冷/热缓存，每组至少运行 10 次，记录中位数、P95、API/网络请求数、DOM 数量及内存。

- 验证侧栏基础操作是否独立于历史统计完成。
- 验证快速连续搜索只提交最后结果，以及虚拟列表不丢失选择。
- 比较旧 Git 版本与新版本；未测量前不宣称固定百分比提升或绝对耗时达标。
- 根据测量决定网格虚拟化、增量历史统计、书签索引局部更新及侧栏局部渲染的优先级。
- 后续模块拆分优先处理仍较大的 shared/utils.js 和页面控制器，保持现有行为及测试。

## 完成条件

已确认的数据丢失风险关闭，两浏览器真实功能与故障验收通过，性能证据可复查，安装、备份兼容与恢复限制准确记录。当前尚未满足全部发布条件。
